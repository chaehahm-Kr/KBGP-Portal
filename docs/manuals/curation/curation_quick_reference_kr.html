K SELECT NETWORK OFFICIAL SOP
큐레이션 실무 퀵 가이드 (Curation Quick Reference Guide)
실무 퀵 참조표 · V1.0
SOP 1: 신규 상품 큐레이션 검토 & 담당 지정 개별 상품 레벨
  1. Products ➔ [Product ID] ➔ Curation 오버라이드 탭 이동.
  2. selection_status === APPROVED 입점 승인 상태 확인.
  3. 담당 큐레이터 드롭다운에서 리드 큐레이터 성명 선택.
  4. Curation Status를 NOT_REVIEWED ➔ APPROVED 변경.
  5. 차기 검토일 지정 후 Save Curation Profile 클릭.
SOP 2: Strategic Role (전략적 역할) 7종 전략 역할 판정
  • HERO: 브랜드 대표 간판 플래그십 상품 (최상위 인지도).
  • CORE: 매출의 기반을 지원하는 매출 효자 베스트셀러.
  • TRAFFIC: 고객 매장 유입을 촉진하는 모객 상품.
  • TREND: SNS 이슈 및 시즌 트렌드 반응형 상품.
  • MARGIN: 리테일러/K SELECT 수익성 극대화 고마진 상품.
  • TRIAL / SUPPORT: 미니 트라이얼 키트 & 루틴 보조 상품.
SOP 3: AP 세트에 상품 추가 (Add Product) AP 세트 빌더
  1. Products ➔ Curation ➔ [Program] ➔ [AP Code] 이동.
  2. 우측 상단 + Add Product 버튼 클릭.
  3. 팝업 검색창에서 상품명, 브랜드, Letusto SKU로 후보 검색.
  4. AP Priority Role (REQUIRED / CORE / OPTIONAL) 선택.
  5. Add to AP Set 클릭 후 테이블 반영 확인.
SOP 4: AP 상품 1:1 대체 교체 (Replace) 1:1 상품 교체
  1. AP 세트 빌더 테이블에서 교체 대상 상품 행 이동.
  2. Actions 열의 Replace 버튼 클릭.
  3. 팝업에서 동일 카테고리의 활성 대체 SKU 검색 및 선택.
  4. Confirm Replacement 클릭.
  5. 신규 상품이 기존 상품의 Priority Role을 그대로 승계.
SOP 5: Target SKU 수량 검증 어소트먼트 점검
  • START_4FT: Target = 10개 SKU
  • GROW_8FT: Target = 25개 SKU
  • EXPAND_12FT: Target = 45개 SKU
  • Selected SKU === Target SKU (초록색 Match 배지) 확인.
  • 수량 불일치(주황색) 시 상품을 추가/제외하여 수량 맞춤.
SOP 6: 단종(DISCONTINUED) 상품 안전 교체 안전 관리
  1. 테이블 내 빨간색 DISCONTINUED 배지 확인.
  2. 해당 행의 Replace 버튼 클릭.
  3. 동일 카테고리의 정상 판매 중인 대체 상품 선택.
  4. Category & Brand Mix 차트의 정상 갱신 확인.
응급 문제 해결 퀵 참조표 (TROUBLESHOOTING CHEAT SHEET)
발생 증상 원인 진단 즉시 조치 방법
추가 팝업에 후보 상품이 검색되지 않음 selection_status !== APPROVED Products 목록에서 입점 승인(APPROVED) 처리 후 재검색.
Target SKU와 Selected SKU 수량이 안 맞음 목표 수량 대비 미달 또는 초과 상태 Selected === Target SKU 가 될 때까지 추가 또는 제외 조치.
Matching Tag 검색 결과가 안 나옴 마스터 테이블에 태그 미등록 상태 Settings ➔ Curation ➔ Tag Manager 에서 태그 신규 생성.
시뮬레이터 추천 결과가 달라짐 AP 매트릭스 우선순위 최근 수정 영향 시뮬레이터 샌드박스 재계산을 통해 최신 AP 세트 검증.
