# K SELECT Brand Portal — Internal UX & System Audit Notes

본 문서는 **Brand Onboarding Manual Screenshot Asset Pack**을 제작하면서 실제 K SELECT NETWORK 및 Brand Portal 시스템을 전수 점검하여 도출한 **내부 개선점 및 실무 가이드 노트**입니다. 향후 포털 UI/UX 고도화 및 고객 응대(CS) 가이드로 활용할 수 있습니다.

---

## 1. 사전 준비 자료 체크리스트 (Onboarding Checklist)

브랜드사가 가입부터 제품 등록 완료까지 차질 없이 진행하기 위해 사전에 준비해야 하는 authoritative 항목 목록입니다.

### A. 회사 및 담당자 정보 (Company & Contacts)
- [ ] 사업자등록증 사본 (법인/개인)
- [ ] 본사 영문 주소 및 우편번호 (글로벌 계약용)
- [ ] 출하지(Shipping Origin) 센터 주소, 우편번호, 담당 창고 연락처
- [ ] 실무 담당자 국문 성명 및 여권 기준 영문 First Name / Last Name (박은애 → Eun-ae Park)
- [ ] 업무 영역별 담당자 지정 (제품, 물류, 정산, 법무)

### B. 브랜드 정보 (Brand Data)
- [ ] 브랜드 공식 국문명 및 영문명
- [ ] 브랜드 로고 고해상도 이미지 (PNG 투명배경 또는 SVG, 최소 500x500px 권장)
- [ ] 브랜드 스토리 및 철학 (200~500자 요약)
- [ ] 공식 온라인 몰 또는 SNS 계정 URL

### C. 제품 사양 및 물류 데이터 (Product & Logistics Specs)
- [ ] 제품별 사내 고유 제조사 품번 (Manufacturer SKU)
- [ ] 국문/영문 정식 제품명
- [ ] 단품(Item) 개별 박스 치수 (가로×세로×높이 cm) 및 총중량(g)
- [ ] 마스터 카톤(Master Carton) 입수량 (예: 1박스당 24개/48개 등)
- [ ] 마스터 카톤 아웃박스 치수 (가로×세로×높이 cm) 및 총중량(kg) → CBM 자동 산출
- [ ] 팔레트당 적재 박스 수량 (선택)
- [ ] 미국 표준 12자리 UPC 바코드 또는 한국 표준 13자리 880 EAN 바코드 번호

### D. 가격 정책 (Pricing)
- [ ] 국내 소비자가격 (KRW MSRP)
- [ ] 미국 수출용 FOB 선적도 공급가 (USD)

### E. 서류 및 이미지 (Documents & Images)
- [ ] 대표 제품 고화질 이미지 (1:1 정방형, 흰색 배경, 최소 1000×1000px, JPG/PNG)
- [ ] 전성분 텍스트 (단상자 표기 기준)
- [ ] 국문/영문 전성분 증명서 (PDF) 또는 공인 시험성적서

## 2. 사용자 혼선 가능 지점 (Common Confusion Points)

실제 브랜드사 담당자가 포털 사용 중 문의하거나 헷갈릴 수 있는 핵심 지점과 해결 가이드입니다.

| 화면 / 영역 | 주요 혼선 요인 | 시스템 동작 및 권장 안내 |
| :--- | :--- | :--- |
| **담당자 성명 입력** | 국문 성명만 입력하고 영문 성명을 비워두는 경우 | K SELECT는 글로벌 바이어와의 PO 및 통관 서류 연동을 위해 영문 성명이 필수입니다. 여권 철자와 동일한 First/Last Name 입력을 안내해야 합니다. |
| **마스터 카톤 입수량** | 기본값이 없어서 비워두거나 `0`으로 입력하는 경우 | 마스터 카톤 입수량(`carton_pack_qty`)은 필수값이며, 실제 수출용 아웃박스에 패킹되는 단품 개수를 정확히 입력해야 물류비가 정상 산정됩니다. |
| **CBM 계산** | CBM 단위를 수동으로 환산하려고 하는 경우 | 가로, 세로, 높이(cm)를 입력하면 시스템이 `(W × D × H) / 1,000,000` 공식으로 CBM을 자동 산출하므로 별도 계산이 불필요함을 안내합니다. |
| **FOB 가격 단위** | 원화(KRW)와 달러(USD) 공급가를 혼동하는 경우 | 국내 소비자가는 **KRW**, 수출 공급가는 **USD (FOB 부산항/인천공항 기준)**입니다. 환율 변동을 감안하여 USD 기준으로 입력하도록 안내합니다. |
| **바코드(UPC/EAN) 부재** | 신제품이어서 아직 바코드가 발급되지 않은 경우 | 무작위 가짜 번호를 입력하지 말고, `식별 관리 번호` 섹션의 `바코드 지원 문의` 버튼을 통해 K SELECT 바코드 발급 지원을 받도록 안내합니다. |
| **3-Depth 카테고리** | 1Depth만 고르고 2/3Depth를 선택하지 않고 저장 시도 | 카테고리는 반드시 1Depth(대) → 2Depth(중) → 3Depth(소)까지 3단계를 모두 선택해야 카테고리 전용 속성 필드가 활성화되고 저장이 완료됩니다. |

## 3. UI/UX 개선 제안 사항 (Internal Improvement Opportunities)

실제 사용자 여정을 진행하며 확인된 향후 포털 고도화 권장 사항입니다.

1. **Category Select UI 직관성 개선**:
   - 1Depth 선택 시 2Depth와 3Depth 드롭다운이 즉시 시각적으로 강조되도록 인라인 가이드 텍스트(예: *"소분류까지 모두 선택해주세요"*)를 보강하면 사용자 누락을 줄일 수 있습니다.
2. **Logistics Dimension 단위 인라인 툴팁**:
   - 단품 규격은 `cm / g`, 마스터 카톤 규격은 `cm / kg` 단위가 폼 라벨에 직관적으로 강조되어 있어 훌륭하나, `파운드(lb) / 인치(inch)` 자동 변환 결과가 실시간으로 더 눈에 띄게 렌더링되면 북미 수출 담당자들의 편의성이 극대화됩니다.
3. **Draft 저장 후 재진입 시 미완료 필드 하이라이트**:
   - `보완대기 (Draft)` 상태인 제품을 열었을 때, `등록완료`를 위해 아직 입력되지 않은 필수 항목들을 상단 배너에 *"아직 마스터 카톤 규격과 전성분표 서류가 입력되지 않았습니다"* 형태로 요약 리스트업해주면 온보딩 완료율이 크게 향상됩니다.
4. **온라인 입점 신청서 → 포털 계정 자동 연결 (One-Click Onboarding)**:
   - 마케팅 사이트에서 제출한 입점 신청서의 회사 정보와 담당자 정보가 승인 즉시 포털 회사 프로필에 100% 프리필(Pre-fill)되어 브랜드사가 동일한 정보를 두 번 입력할 필요가 없도록 완벽히 유지되고 있습니다.
