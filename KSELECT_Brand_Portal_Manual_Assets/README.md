# K SELECT Brand Portal — Onboarding Manual Screenshot Asset Pack

K SELECT NETWORK 한국 브랜드 파트너사 미팅 및 온보딩 매뉴얼 제작을 위한 **공식 Screenshot Asset Pack**입니다.  
실제 운영 중인 웹사이트(`www.kselectnetwork.com`) 및 브랜드 포털(`portal.kselectnetwork.com`)의 라이브 화면을 기반으로 2x 고해상도 Retina 캡처 및 단계별 UI 콜아웃 주석이 포함되어 있습니다.

## 🎨 Claude Design 활용 가이드

1. **Clean Version (`01_Clean_Screenshots/`)**: 디자이너가 자체 디자인 툴에서 커스텀 화살표, 목업 프레임, 레이아웃을 직접 구성할 때 사용합니다.
2. **Annotated Version (`02_Annotated_Screenshots/`)**: 시스템에서 제공하는 표준 번호 콜아웃(①, ②, ③) 위치와 하이라이트 박스를 참조하여 설명 레이아웃을 잡을 때 사용합니다.
3. **Overview Diagram (`03_Onboarding_Flow/`)**: 매뉴얼의 인트로/목차 페이지에서 전체 진행 순서를 시각화하는 다이어그램으로 사용합니다.
4. **Description Texts (`04_Screenshot_Guide/`)**: 각 화면별 설명 텍스트 카드와 필수값 팁(Callout Tips) 작성에 그대로 활용할 수 있습니다.
