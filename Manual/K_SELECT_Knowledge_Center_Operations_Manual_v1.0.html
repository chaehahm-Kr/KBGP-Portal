SECTION 01
Knowledge Center란?

K SELECT Knowledge Center는 단순한 문서 저장소나 PDF 파일 보관함이 아닙니다. 플랫폼 전체(Manual, Policy, FAQ, System Rule, Admin Guide, Brand Guide, Retailer Guide)의 공통 Source of Truth (단일 진실 출처) 역할을 수행하는 장기 운영 지식 중앙 통제 모듈입니다.

기억할 한 문장
PDF를 보관하는 곳이 아니라, K SELECT의 현재 운영 기준과 정책을 안전하게 관리하는 곳입니다.
📌 Single Source of Truth
여러 부서와 시스템에 파편화될 수 있는 운영 규칙과 정책을 하나의 검증된 중앙 데이터베이스로 일원화하여 관리를 보장합니다.
🔒 Strict Audience Isolation
INTERNAL, ADMIN, BRAND, RETAILER, PUBLIC 5단계 권한 엔진이 데이터 수집(Retrieval) 레벨에서 외부 유출을 원천 차단합니다.
🔄 Immutable Versioning
기존 운영 기준을 직접 덮어쓰지 않고, 버전 이력(v1.0 -> v1.1)을 스냅샷으로 보존하며 안전하게 승인 및 개정합니다.
⚡ Live System Rule Impact
실제 Insights/어드민 시스템 설정값이 변경되면 관련 지식 항목을 감지하여 `POTENTIALLY_OUTDATED` 상태로 검토 요청을 자동 생성합니다.
⚠️ Knowledge Record vs PDF Manual 차이점
Knowledge Record: 시스템 데이터베이스에 저장되는 최우선 표준 지식 (Source of Truth)
PDF Manual Asset: 시각적 배포 및 교육을 위해 연결된 부속 문서 (Asset)
* 따라서 PDF 파일만 교체하고 Knowledge Record의 내용이나 버전을 업데이트하지 않는 조치는 엄격히 금지됩니다.

언제 Knowledge Center를 사용하는가?

실무자는 업무 중 발생하는 다양한 상황에 따라 다음과 같이 Knowledge Center를 활용합니다.

실무 상황 (Situation) 이동 화면 (Menu / Tab) 실무자 행동 가이드 (Action)
"어떤 메뉴나 기능의 사용법을 모르겠습니다." Library 탭 검색창에 메뉴명(예: Topic Score, Fact Check) 입력 후 MANUAL 또는 GUIDE 조회
"현재 적용 중인 공식 운영 정책을 확인하고 싶습니다." Library 탭 Type 필터를 POLICY 또는 SYSTEM_RULE로 선택하여 최신 PUBLISHED 건 확인
"신규 운영 매뉴얼 PDF가 완성되었습니다." + Create Knowledge Type을 MANUAL로 선택, 정보 작성 후 4단계에서 PDF Asset 파일 연결
"기존 정책이나 승인 기준이 변경되었습니다." Detail → VERSIONS 탭 기존 글 직접 수정 금지 ❌ → Create New Version 버튼을 눌러 v1.1 Draft 작성 및 승인 배포
"외부 브랜드/리테일러에 공개해도 되는지 검증이 필요합니다." Detail → ACCESS 탭 Audience 확인 및 Preview As (Brand / Retailer) 기능으로 시뮬레이션 검증
"어드민 시스템 설정(Rule)이 변경되었습니다." Review & Updates 탭 System Change Impact 항목에서 POTENTIALLY_OUTDATED 상태 건 재검토 수행
💡 실무 추천 이동 경로 (Recommended Navigation Flow)
일상 업무: Admin → Settings → Knowledge Center → Library에서 검색 및 조회
정책 변경 시: Knowledge Detail → VERSIONS → Create New Version → Review & Publish

화면 구조 및 Overview 대시보드 활용법

Knowledge Center는 어드민 좌측 사이드바 Admin → Settings → Knowledge Center로 진입하며, 상단 3개 탭으로 구성됩니다.

📊 1. Overview
지식 센터의 전체 지표, 요약 카운트, 조치가 필요한 항목(Needs Your Attention)을 한눈에 보는 대시보드입니다.
📚 2. Library
등록된 모든 지식을 검색, 유형/권한별 필터링하고 상세 내용을 확인하는 실무 중심 검색 화면입니다.
🔔 3. Review & Updates
외부 공개 승인 대기(Awaiting Approval), 검토 필요, 시스템 변경 영향(System Impact)을 관리합니다.
SECTION 04 — OVERVIEW MONITORING

Overview에 출근 후 접속하면 모든 숫자를 일일이 확인할 필요 없이, Needs Your Attention 섹션을 가장 먼저 확인합니다.

PUBLISHED 지식 현황
현재 정상 운영 적용 중인 지식 총 건수입니다.
DRAFT / IN_REVIEW 초안
작성 중이거나 개정 검토 중인 지식 항목 수입니다.
EXTERNAL REVIEW 승인 대기
Brand / Retailer / Public 공개를 위해 외부 검토가 요청된 수입니다.
OUTDATED 영향 받은 지식
어드민 시스템 설정 변경으로 재검토가 필요한 지식 항목 수입니다.

SECTION 06
Knowledge Type 가이드

지식을 새롭게 등록할 때 기술적 정의가 아닌 "어떤 경우 이 Type을 선택해야 하는가?"를 기준으로 정합니다.

Type 실무 정의 (Operational Definition) 선택 가이드 (When to Choose)
MANUAL 종합 운영 지침서 및 공식 매뉴얼 PDF 가이드북 파일과 함께 전체 시스템을 안내할 때
POLICY 회사의 공식 운영 원칙 및 규정/기준 실무자가 반드시 지켜야 하는 원칙이나 위험 관리 기준 지정 시
SOP 표준 운영 절차 (Standard Operating Procedure) 업무를 순서대로 진행해야 하는 단계별 프로세스 안내 시
SYSTEM_RULE 실제 시스템 설정(Setting)과 연동된 운영 기준 어드민 설정값(점수, 시간, 수량 등)과 연동되어 관리가 필요할 때
DEFINITION 용어, 상태(Status), 필드 및 메트릭의 정합성 정의 상태 코드나 분류의 의미를 명확히 정의할 때
GUIDE 시스템 실행 결과 해석 및 장애 처리 안내 가이드 에러 코드 해석이나 특정 대시보드 상태를 안내할 때
FAQ 자주 묻는 질문과 답변 안내 브랜드사나 리테일러가 자주 묻는 질문을 정리할 때
💡 Type 선택 팁
시스템 설정(Setting) 변경에 따라 자동으로 영향을 받아야 한다면 SYSTEM_RULE (Source Type: HYBRID)을 선택하세요.

SECTION 08
Audience & 보안 정책 (Deny-by-Default)

Knowledge Center는 데이터 리트리버(Retrieval) 레벨에서 무권한 열람을 차단하는 Deny-by-Default 보안 엔진을 사용합니다.

보안 절대 수칙
모든 신규 Knowledge의 기본값은 INTERNAL ONLY입니다.
외부 공개를 확신할 수 없으면 INTERNAL 상태를 유지하세요.
Audience 구분 열람 가능 대상 (Authorized Role) 보안 격리 상태
INTERNAL K SELECT 내부 임직원 및 어드민 관리자 전용 외부 브랜드/리테일러 검색 0건 (원천 차단)
ADMIN / MANAGEMENT Super Admin 및 경영진/승인권자 전용 내부 일반 편집자에게도 제한 가능
BRAND 입점 한국 브랜드사 파트너 (포털 로그인 계정) 외부 검토 승인 후 공개 가능
RETAILER 미국 오프라인 뷰티 수플라이 / 리테일 바이어 외부 검토 승인 후 공개 가능
PUBLIC 인증 없이 방문하는 모든 외부 이용자 최고 단계 승인 후 공개 가능
🔒 Retrieval Level Security 조치
화면 UI에서 숨기는 방식이 아닙니다. 서버 데이터베이스 조회 시 권한이 없는 계정(Brand/Retailer)으로 요청되면 API 결과 배열 자체가 0건으로 반환됩니다.

SECTION 09 & 10
External Publication & Sensitive Internal

외부 Audience(BRAND, RETAILER, PUBLIC)를 지정할 때는 엄격한 승인 워크플로우와 민감 정보 차단 절차를 거칩니다.

1️⃣ External Review Request
외부 공개 지정 시 즉시 IN_REVIEW로 전환되며 관리자에게 승인 요청이 전달됩니다.
2️⃣ Preview As 시뮬레이션
승인 전 Preview As Brand 또는 Preview As Retailer로 실제 외부 화면을 미리 검증합니다.
⛔ 외부 공개 자료 절대 포함 금지 항목 (Prohibited Items)
Brand 또는 Retailer 공개 자료에는 다음 영업 비밀 및 영업 기밀 정보가 절대로 포함되어서는 안 됩니다:
  • 내부 마진율 계산 로직 (Margin Logic & FOB Margin Weight)
  • 공급가 원가 (Supplier Cost & Sourcing Cost)
  • 내부 브랜드/제조사 심사 가중치 점수표
  • 미국 리테일러 바이어 협상 가이드라인 (Negotiation Rules)
  • 자사 고유 알고리즘 (Proprietary Score Logic)
SECTION 10 — SENSITIVE INTERNAL

지식 등록 시 Is Sensitive Internal 스위치를 활성화하면 내부 직원 중에서도 높은 보안 등급으로 지정되며 외부 공개 전환이 철저히 차단됩니다.

⚠️ Sensitive Internal 조치 수칙
`Sensitive Internal`로 지정된 지식 항목을 훗날 외부 공개(BRAND/RETAILER)로 변경하려면, 비공개 마진/원가/알고리즘 문구가 완전히 삭제되었는지 2인 이상의 승인권자 재검토가 필요합니다.

Review & Updates 대시보드 및 System Impact

Review & Updates 화면은 지식 센터가 항상 최신성을 유지하도록 3가지 검토 영역을 제공합니다.

1. Awaiting Approval
외부 공개(Brand/Retailer) 승인이 필요한 지식 목록
2. Needs Review
작성 중이거나 수정 요청된 초안 목록
3. System Impact
시스템 설정 변경으로 검토가 필요한 항목

SECTION 18
실무자를 위한 DO & DON'T

Knowledge Center를 운영할 때 실무자가 반드시 준수해야 할 6대 권장사항(DO)과 6대 절대 금지사항(DON'T)입니다.

✅ DO (권장 수칙)
  • DO 1: 신규 등록 시 최우선적으로 INTERNAL ONLY를 적용하세요.
  • DO 2: 정책 변경 시 Create New Version으로 개정 이력을 보존하세요.
  • DO 3: 외부 공개 전 Preview As로 시뮬레이션 검증을 수행하세요.
  • DO 4: 시스템 변경 알림(Outdated) 발생 시 사유를 확인하고 조치하세요.
  • DO 5: PDF 파일명, 표지 버전, Knowledge Record 버전을 일치시키세요.
  • DO 6: 세부 지식에 연관 모듈, 라우트, 상위 매뉴얼 관계를 연결하세요.
❌ DON'T (절대 금지 수칙)
  • DON'T 1: 이미 PUBLISHED된 지식을 몰래 직접 덮어쓰지 마세요.
  • DON'T 2: 마진, 원가, 내부 심사점수를 외부 공개 지식에 포함하지 마세요.
  • DON'T 3: PDF 파일만 슬그머니 교체하고 버전을 유지하지 마세요.
  • DON'T 4: 테스트 목적으로 실제 어드민 System Rule을 임의 변경하지 마세요.
  • DON'T 5: 오래된 SUPERSEDED 지식을 검증 없이 최신 정책으로 인용하지 마세요.
  • DON'T 6: 외부 공개 승인 요청 절차 없이 외부 파트너에 지식을 전달하지 마세요.
