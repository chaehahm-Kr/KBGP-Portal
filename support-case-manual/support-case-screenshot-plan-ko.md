# Support Case 매뉴얼 화면 캡처 계획서 (Screenshot Plan)

본 문서는 **Support Case 운영 매뉴얼 원본 패키지**에 포함된 총 15종의 캡처 자산에 대한 목적, 수집 경로, 강조 영역(Highlight Box) 및 숫자 마커(Step Marker) 배치 지침을 정리한 가이드 문서입니다.

---

## 1. 캡처 자산 저장 구조

```text
support-case-manual/
├── assets/
│   ├── raw/                  # 원본 고해상도 데스크탑 캡처 (1440x900, Retina 2x)
│   │   ├── PORTAL-01-LIST.png
│   │   ├── ...

```

## 2. 화면별 캡처 지침 및 마커 정의

### A. Brand Portal (파트너 사용자 화면)

#### 1. `PORTAL-01-LIST` (Support 목록 및 필터)
- **화면 경로**: `/portal/support`
- **목적**: 파트너사의 문의 지원 목록, 검색창 및 4대 상태 필터 탭 구조 설명
- **강조 박스**: 검색 입력창 및 4대 상태 필터 탭
- **마커 1**: 검색어 입력창 (제목/케이스번호/내용 검색)
- **마커 2**: 4대 상태 필터 (전체/접수됨/검토중/조치필요/종료됨)

#### 2. `PORTAL-02-NEW-MODAL` (새 1:1 문의 작성 모달)
- **화면 경로**: `/portal/support` → `[새 문의 작성]` 버튼 클릭
- **목적**: 파트너사의 신규 Support Case 등록 작성 폼 안내
- **강조 박스**: 문의 유형 선택, 제목, 내용, 첨부파일 영역
- **마커 1**: 문의 유형 (입점/제품/물류/정산/시스템/기타)
- **마커 2**: 문의 제목 입력
- **마커 3**: 상세 문의 내용 작성 (최대 20MB 첨부파일 포함)

#### 3. `PORTAL-03-CONVERSATION` (대화 내용 탭)
- **화면 경로**: `/portal/support` → 케이스 상세 선택
- **목적**: 사람과 사람이 주고받은 실질 대화 메시지 및 파일 첨부 확인
- **강조 박스**: `💬 대화 내용 (Conversation)` 탭
- **마커 1**: 대화 내용 탭 선택 버튼 (사람 작성 메시지 100% 표출)

#### 4. `PORTAL-04-CASELOG` (처리 기록 탭)
- **화면 경로**: `/portal/support` → 케이스 상세 → `[Case Log]` 탭
- **목적**: 접수, 상태 변경, 담당자 배정, 종료 등 시스템 Audit Trail 확인
- **강조 박스**: `📋 Case Log (처리 기록)` 탭
- **마커 1**: Case Log 탭 선택 버튼 (시스템 이력 전용)

#### 5. `PORTAL-05-ACTION-REQ-BANNER` (조치 필요 케이스 배너)
- **화면 경로**: `/portal/support` → `ACTION_REQUIRED` 케이스 선택
- **목적**: 어드민의 조치 요청 수신 시 파트너 화면의 붉은색 배너 및 조치 버튼 안내
- **강조 박스**: `[조치 완료 작성 및 검토 요청]` 버튼
- **마커 1**: 조치 완료 작성 모달 오픈 버튼

#### 6. `PORTAL-06-RESOLVE-MODAL` (조치 완료 작성 모달)
- **화면 경로**: `/portal/support` → `[조치 완료 작성 및 검토 요청]` 클릭
- **목적**: 파트너사의 조치 수행 내용 작성 및 증빙 파일 제출
- **강조 박스**: 조치 내용 텍스트 영역 및 제출 버튼
- **마커 1**: 조치 완료 세부 내용 입력
- **마커 2**: 제출 및 검토 요청 버튼 (상태: `ACTION_REQUIRED → UNDER_REVIEW` 전이)

#### 7. `PORTAL-07-CLOSE-MODAL` (문의 종료 확인 모달)
- **화면 경로**: `/portal/support` → `[문의 종료]` 클릭
- **목적**: 파트너사의 명시적 케이스 종료 Confirm 팝업
- **강조 박스**: 종료 처리 확정 버튼
- **마커 1**: 종료 처리 확정 버튼 (상태: `CLOSED` 전이)

#### 8. `PORTAL-08-RATING` (종료 케이스 만족도 평가)
- **화면 경로**: `/portal/support` → `CLOSED` 케이스 선택
- **목적**: 종료된 케이스에 대한 별점 (1~5점) 및 평가 의견 작성
- **강조 박스**: 파트너 만족도 평가 카드
- **마커 1**: 별점 선택 및 서술형 의견 입력 폼 (CLOSED 케이스 전용)

#### 9. `PORTAL-09-FOLLOWUP` (후속 문의 생성 버튼)
- **화면 경로**: `/portal/support` → `CLOSED` 케이스 하단
- **목적**: 종료 케이스 관련 추가 문의 발생 시 새 후속 문의 생성 안내
- **강조 박스**: `[후속 문의하기]` 버튼
- **마커 1**: 후속 문의하기 버튼 (이전 케이스 `#CASE-XXXX` 데이터 연동)

---

### B. Admin (관리자 파트너 문의 화면)

#### 10. `ADMIN-01-LIST` (Admin Partner Inquiries 목록)
- **화면 경로**: `/admin/partner-inquiries`
- **목적**: 어드민 담당자의 전체 파트너 문의 목록 및 4대 상태 필터 관리
- **강조 박스**: 검색창 및 공식 상태 필터
- **마커 1**: 통합 검색창 (회사명/케이스번호/제목/내용)

#### 11. `ADMIN-02-CONVERSATION` (Admin 대화 내용 탭)
- **화면 경로**: `/admin/partner-inquiries` → 케이스 선택
- **목적**: 파트너사 문의 내용 및 어드민 조치 요청 메시지 100% 확인
- **강조 박스**: 대화 내용 스크롤 영역

#### 12. `ADMIN-03-CASELOG` (Admin Case Log 탭)
- **화면 경로**: `/admin/partner-inquiries` → `[Case Log]` 탭
- **목적**: 상태 변동, 담당자 배정, 파트너 조치 완료 접수 기록 확인

#### 13. `ADMIN-04-REPLY-FORM` (Admin 3-Action Group 답변 영역)
- **화면 경로**: `/admin/partner-inquiries` → 하단 답변 작성 폼
- **목적**: 답변 작성 및 3가지 Action 버튼 그룹 사용법 안내
- **강조 박스**: 3-Action Group (`[답변 등록]`, `[🔒 답변 등록 후 케이스 종료]`, `[🔒 답변 없이 케이스 종료]`)
- **마커 1**: `[답변 등록]` (상태 유지)
- **마커 2**: `[🔒 답변 등록 후 케이스 종료]` (답변 작성 + CLOSED)
- **마커 3**: `[🔒 답변 없이 케이스 종료]` (답변 없이 CLOSED)

#### 14. `ADMIN-05-ACTION-REQUIRED-TOGGLE` (조치 요청 포함 체크박스)
- **화면 경로**: `/admin/partner-inquiries` → 답변 작성 폼
- **목적**: 파트너사 추가 조치 요청 시 `ACTION_REQUIRED` 상태 지정
- **강조 박스**: `⚠️ 조치 요청 포함` 체크박스
- **마커 1**: 조치 요청 포함 체크박스 선택

#### 15. `ADMIN-06-CLOSED-INFO` (Admin 종료 케이스 및 만족도 확인)
- **화면 경로**: `/admin/partner-inquiries` → `CLOSED` 케이스 선택
- **목적**: 종료 시각, 종료 주체 및 파트너사가 남긴 만족도 별점/의견 조회
- **강조 박스**: 케이스 종료 뱃지 및 파트너 만족도 카드
- **마커 1**: 파트너 만족도 별점 및 서술형 의견 표시 카드
