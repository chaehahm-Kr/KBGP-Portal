# K SELECT Brand Portal 입점 신청 및 리테일 네트워크 가이드

- **문서 번호:** `MAN-B-RET-001`  
- **버전:** `v1.0`  
- **대상:** 브랜드사 대표, 브랜드 관리자, 해외영업 및 운영 담당자 (`Audience Code: B`)  
- **표준 토픽:** `입점 & 리테일 네트워크 (topic-retail)`  

---

## 1. 개요 및 파트너십 프로세스

### 1.1 K SELECT Retail Network 입점 구조
K SELECT NETWORK의 **입점 신청(Retail Placement Application)** 모듈은 북미 시장 진출을 희망하는 브랜드 파트너사가 등록된 제품을 선택하여 공식 심사를 신청하고, 전문 MD(Merchandiser) 팀과의 실시간 검토 및 추가 자료 소통을 통해 북미 리테일 유통망에 입점하도록 지원하는 핵심 시스템입니다.

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│ 1. 상품 선택    │ ──> │ 2. 준비사항 응답│ ──> │ 3. 제출 & MD심사│ ──> │ 4. 승인 및 입점 │
│ (다중 브랜드)   │     │ (6대 Readiness) │     │ (실시간 타임라인)│    │ (파트너십 확정) │
└─────────────────┘     └─────────────────┘     └─────────────────┘     └─────────────────┘
```

### 1.2 신청 전 필수 사전 준비
입점 신청서를 작성하기 전에 다음 항목이 브랜드 포털에 정상적으로 등록되어 있어야 합니다.

1. **브랜드 등록 완료 (`MAN-B-BRAND-001`)**: 회사 계정에 입점할 브랜드가 등록되어 있어야 합니다.
2. **상품 카탈로그 등록 완료 (`MAN-B-PROD-001`)**: 신청 대상 상품의 기본 정보, 규격, 카테고리가 등록되어 있어야 합니다.
3. **북미 규정 및 MoCRA 대응 확인 (`MAN-B-REG-001`)**: 미국 FDA 및 MoCRA 규제 준수 여부를 사전에 확인해야 합니다.

## 2. 신청 현황 대시보드 (`/portal/applications`)

### 2.1 대시보드 화면 구성
브랜드 포털 좌측 메뉴에서 **[입점 신청]**을 클릭하면 현재까지 제출된 신청서 목록과 진행 상태를 한눈에 확인할 수 있습니다.

- **새 신청서 작성 버튼**: 신규 입점 신청서를 생성합니다. (`application:write` 권한 필요)
- **신청 번호**: 공식 발급된 신청 식별 번호입니다. 클릭 시 상세 워크스페이스로 이동합니다. (임시저장 상태인 경우 `(임시저장 상태)`로 표시)
- **신청 상태**: 현재 심사 진행 상태를 나타내는 컬러 뱃지입니다.
- **포함 제품 수**: 해당 신청서에 포함된 제품의 총 개수입니다.
- **최종 변경일**: 최근 수정일 또는 공식 제출일입니다.

### 2.2 신청 상태 뱃지 체계

| 상태 코드 | 한글 표기 | 뱃지 색상 | 상태 설명 |
| :--- | :--- | :--- | :--- |
| `draft` | **임시저장** | 회색 (Zinc) | 신청서 작성 중인 상태로 자유롭게 수정 가능 |
| `submitted` | **제출됨 / 접수** | 파란색 (Blue) | 신청서 제출 완료 후 심사 대기 중인 상태 |
| `under_review` | **심사중** | 파란색 (Blue) | K SELECT MD 심사팀이 제품별 심사를 진행 중인 상태 |
| `info_requested` | **추가자료요청** | 주황색 (Amber) | MD가 보완 서류 또는 성분/규격 자료를 요청한 상태 |
| `re_review` | **재검토중** | 파란색 (Blue) | 브랜드사가 추가 자료를 회신하여 재심사 대기 중인 상태 |
| `partial_approved`| **부분승인** | 초록색 (Emerald) | 신청 제품 중 일부 품목이 입점 승인된 상태 |
| `approved` | **승인됨** | 초록색 (Emerald) | 신청서의 모든 제품이 입점 승인 완료된 상태 |
| `on_hold` | **보류** | 주황색 (Amber) | 추가 협의나 외부 요인으로 심사가 일시 보류된 상태 |
| `rejected` | **반려됨** | 빨간색 (Rose) | 심사 기준 미충족으로 신청이 반려된 상태 |

## 3. 신규 입점 신청서 작성 (Draft Mode)

### 3.1 드래프트 생성 및 다중 브랜드 제품 선택
1. 대시보드 상단의 **[새 신청서 작성]** 버튼을 클릭합니다.
2. 시스템이 새로운 드래프트를 생성하고 작성 화면(`/portal/applications/[id]`)으로 진입합니다.
3. **제품 선택 섹션**에서 입점을 신청할 제품을 체크합니다.
   - 회사에 등록된 여러 브랜드의 제품이 브랜드별로 자동 그룹화되어 표시됩니다.
   - 한 번의 신청서에 서로 다른 브랜드의 제품을 복수 선택하여 동시에 신청할 수 있습니다.

### 3.2 6대 프로그램 참여 준비 사항 (Readiness Criteria)
북미 파트너십 추진을 위해 다음 6개 준비 사항에 대해 자가진단을 수행합니다.

| 번호 | 준비 사항 항목 | 세부 설명 및 기준 | 선택 항목 |
| :---: | :--- | :--- | :--- |

### 3.3 임시저장 및 제출 유효성 검증
- **임시저장**: 하단의 **[임시저장]** 버튼을 클릭하면 선택한 제품과 준비사항 응답이 저장되며, 언제든지 다시 방문하여 수정할 수 있습니다.
- **신청서 제출**:
  - 제품을 최소 1개 이상 선택해야 제출 버튼이 활성화됩니다.
  - **[신청서 제출]** 클릭 시 공식 신청번호(예: `APP-20261001-0001`)가 자동 발급되며 상태가 `제출됨(submitted)`으로 변경됩니다.
  - 제출 완료 후에는 내용의 직접 수정이 불가능하며 심사 단계로 전환됩니다.

## 4. 실시간 심사 현황 및 타임라인 모니터링

### 4.1 제품별 개별 심사 상태 및 이력
신청서 상세 페이지 좌측에는 신청된 각 제품별 심사 현황 테이블이 표시됩니다.

- **제품별 심사 상태**: 각 제품마다 독립적으로 `검토대기`, `심사 진행 중`, `보완 요청`, `심사 보류`, `심사 반려`, `심사 승인` 상태가 표시됩니다.
- **실시간 감사 타임라인**: 각 제품 아래에 접수 일시부터 상태 변경 내역, 타임스탬프, MD가 작성한 구체적 심사 사유(`↳ 사유: ...`)가 기록됩니다.

### 4.2 자동 상태 집계 엔진 (`computeAggregatedStatus`)
K SELECT 시스템은 개별 제품의 심사 결과에 따라 신청서 전체 상태를 자동으로 집계합니다.

- **심사중 (`under_review`)**: 아직 심사 중이거나 보완 요청 중인 제품이 1건 이상 존재하는 경우
- **승인됨 (`approved`)**: 신청서에 포함된 모든 제품(100%)이 승인된 경우
- **반려됨 (`rejected`)**: 신청서에 포함된 모든 제품(100%)이 반려된 경우
- **부분승인 (`partial_approved`)**: 일부 제품은 승인되고, 일부 제품은 반려 또는 보류된 경우
- **보류 (`on_hold`)**: 승인된 제품이 0건이고 일부 제품이 보류된 경우

## 5. 추가 자료 요청(Info Request) 대응 및 문서 제출

### 5.1 추가 자료 요청 알림
MD 심사역이 성분 분석표(COA), 영문 단상자 라벨링, 미국 상표권 증빙 등 추가 서류를 요청하면:
- 신청서 상세 페이지 상단에 **노란색 긴급 알림 패널**이 활성화됩니다.
- 구체적인 요청 사항과 함께 **회신 기한**(예: `회신 기한: 2026년 10월 8일까지`)이 표시됩니다.
- 계정 담당자에게 안내 이메일 및 1:1 문의 채널 티켓이 동기화됩니다.

### 5.2 회신 작성 및 증빙 서류 업로드
1. 알림 패널 내 회신 내용 입력란에 답변을 작성합니다.
2. 필요한 경우 **[파일 선택]** 버튼을 통해 증빙 파일(PDF, PNG, JPG, WEBP, CSV, XLSX)을 첨부합니다.
3. **[회신 제출]** 버튼을 클릭합니다.
4. 제출 완료 즉시 첨부파일이 안전하게 업로드되고 신청서 상태가 `재검토중(re_review)`으로 자동 전환되며 담당 MD에게 알림이 전달됩니다.

## 6. 사이드바 평가 요약 & 결과 후속 절차 및 FAQ

### 6.1 사이드바 평가 요약
상세 페이지 우측에는 신청 시 제출한 **참여 조건 자가진단 결과(`✅`/`❌`)**와 **프로그램 참여 준비 사항 요약(`🟢 진행 가능`/`🟡 협의 필요`)** 카드가 표시되어 브랜드사와 MD가 동일한 기준을 공유할 수 있습니다.

### 6.2 심사 결과별 후속 조치
- **최종 승인 (`approved`) / 부분 승인 (`partial_approved`)**: 승인된 품목에 대해 K SELECT 북미 유통망 입점 및 후속 비즈니스 협의가 진행되며, 실제 발주는 `MAN-B-ORD-001`의 독립적인 PO 프로세스(브랜드사 발주 요청 또는 본사 직접 발주)를 통해 진행됩니다.
- **심사 보류 (`on_hold`)**: 타임라인에 명시된 보류 사유를 검토하고 MD 담당자와 협의를 진행합니다.
- **심사 반려 (`rejected`)**: 제품별 타임라인에 명시된 공식 반려 사유를 확인하여 제품 스펙 또는 규제 인증 요건을 보완할 수 있습니다. (반려 품목에 대한 재신청 정책은 향후 정책 업데이트 참조)

## 7. 자주 묻는 질문 (FAQ)

### Q1. 입점 신청서는 브랜드별로 따로 작성해야 하나요?
**A:** 아닙니다. 동일 회사 계정에 여러 브랜드가 등록되어 있다면, 하나의 신청서 안에서 여러 브랜드의 제품을 자유롭게 체크하여 한 번에 제출할 수 있습니다.

### Q2. 신청서를 제출한 후 제품을 추가하거나 내용을 수정할 수 있나요?
**A:** `제출됨(submitted)` 상태 이후에는 브랜드사에서 직접 신청서를 수정할 수 없습니다. 내용 변경이 필요한 경우 MD의 추가 자료 요청 시 회신란에 기재하거나 1:1 고객지원 채널을 통해 문의해 주시기 바랍니다.

### Q3. 프로그램 참여 준비 사항(Readiness)에서 '협의 필요'를 선택하면 감점되나요?
**A:** 감점되지 않습니다. '협의 필요'는 초도 물량, 마케팅 협력, 유통 가격 등에 대해 K SELECT MD 팀과 맞춤형 조율을 진행하기 위한 정상적인 협의 절차입니다.

### Q4. 신청서 내 일부 제품만 승인되면 어떻게 되나요?
**A:** 신청서 상태가 `부분승인(partial_approved)`으로 변경되며, 승인된 제품에 대해서만 우선적으로 리테일 네트워크 입점 및 후속 비즈니스 협의가 진행됩니다. 반려/보류된 제품은 영향을 주지 않습니다.

### Q5. MD로부터 추가 자료 요청을 받으면 어떻게 회신하나요?
**A:** 신청서 상세 페이지 상단 노란색 패널에서 요청 내용을 확인하고, 회신 텍스트 및 증빙 파일(PDF, 이미지, 엑셀)을 첨부하여 '회신 제출'을 클릭하시면 됩니다.

### Q6. 제품 심사 반려 사유는 어디에서 확인하나요?
**A:** 상세 페이지의 '제품별 심사 현황' 테이블에서 해당 제품 하단 타임라인의 `↳ 사유: ...` 항목을 통해 MD의 피드백을 확인할 수 있습니다.

### Q7. 입점 승인 후 다음 단계는 무엇인가요?
