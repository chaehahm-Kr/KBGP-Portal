### 3. 핵심 디자인 원칙 (Design Principles)

1. **실제 스크린샷 100% 활용 (Actual Production Screens First)**:
   - 본 패키지에 포함된 스크린샷은 실제 라이브 K SELECT Brand Portal 화면입니다.
   - 가상의 UI를 새로 그리지 마시고, 실제 스크린샷을 우선 배치하십시오.
2. **스크린샷 비주얼 가공 (Visual Enhancement)**:
   - 핵심 기능 위치에 번호 배지(Callout 1, 2, 3), 돋보기 줌(Zoom), 영역 하이라이트 박스, 화살표를 적절히 배치하여 사용자의 시선을 유도하십시오.
   - 원본 스크린샷의 가독성을 해치지 않도록 깔끔하고 세련된 오버레이를 적용하십시오.
3. **Proposed UI 명확한 표기 (Proposed Concept vs Actual Screens)**:
   - 프로덕션에 아직 개발되지 않은 기능(예: '브랜드 정책 팝업 모달')은 매뉴얼 내에서 `Proposed UI Concept` 또는 `향후 지원 예정 기능`으로 명확히 구분하여 디자인하십시오.
4. **비주얼 인포그래픽 & 플로우차트 활용**:
   - `선(先) 브랜드 등록 → 후(後) 상품 등록` 워크플로우를 직관적인 단계별 프로세스 다이어그램으로 시각화하십시오.
   - `브랜드 등록 vs 상표권 등록`의 차이를 비교표(Comparison Table)로 일목요연하게 정리하십시오.
   - `동일 브랜드를 다수 파트너사가 취급하는 구조`를 허브앤스포크 다이어그램으로 표현하십시오.

### 4. 권장 페이지 레이아웃 (Suggested Page Layout Budget)

* **PAGE 1 : 표지 (Cover)**
  - 제목: `K SELECT 브랜드 등록 및 관리 정책`
  - 부제: `Brand Portal User Guide & Operations Policy (MAN-B-BRAND-001)`
  - 공식 로고 배치 및 깔끔한 다크 네이비 테마 디자인
* **PAGE 2 : 왜 브랜드 등록이 필수인가? (Why Brand Registration Matters)**
  - `[회사 계정] → [브랜드 등록] → [상품 등록]` 선행 프로세스 플로우차트
  - 브랜드 미등록 시 상품 등록 불가 안내 및 초기 온보딩 중요성
* **PAGE 3 : 브랜드 등록 vs 상표권(Trademark) 등록 (Comparison)**
  - K SELECT 브랜드 등록(시스템 카탈로그 분류) vs 특허청 상표권(법적 독점권)의 개념 차이 비교표
  - 상표권이 없거나 출원 중이어도 K SELECT 등록이 가능한 이유 및 상표권 등록 시 신뢰도 혜택 설명
* **PAGE 4 : 동일 브랜드를 여러 회사가 취급하는 구조 (Multi-Company Structure)**
  - A사(제조사), B사(총판/벤더), C사(셀러)가 동일 브랜드를 각각 자사 포털에서 등록·운영하는 구조도
* **PAGE 5 : 브랜드 관계 및 권한 정의 (Brand Owner vs Distributor vs Seller)**
  - Brand Owner(원소유사/제조사) 1개사 원칙 및 Authorized Distributor, Seller의 역할 정의
* **PAGE 6 : 브랜드 삭제 불가 정책 (Data Integrity & Delete Protection)**
  - 상품이 연결된 브랜드는 물리 삭제 불가 원칙
  - 과거 거래 내역, 발주 이력, 인보이스 데이터 무결성 보호 배경 설명
* **PAGE 7 : 브랜드 비활성화(사용 중단) 처리 (Active → Inactive Lifecycle)**
  - 미사용 브랜드의 '사용 중단' 처리 방법 및 처리 후 효과 (과거 데이터 유지 + 신규 상품 선택 드롭다운 제외)
* **PAGE 8 : 실제 포털에서 브랜드 관리하기 (Portal Walkthrough with Screenshots)**
  - SS-01 ~ SS-08 스크린샷을 활용한 실무 가이드:
    1. 브랜드 관리 메인 대시보드 (`SS-01`, `SS-02`)
    2. 신규 브랜드 등록 및 로고/소개 입력 (`SS-03`)
    3. 대한민국 & 미국 상표권 번호 및 증빙 서류 첨부 (`SS-08`)
    4. 브랜드 정보 수정 및 증빙 파일 관리 (`SS-04`)
    5. 상품 등록 시 브랜드 선택 및 바로가기 연계 (`SS-06`)
    6. 브랜드 사용 중단 실행 (`SS-07`)
* **PAGE 9 : 브랜드 관리 핵심 원칙 요약 (Quick Reference Summary Checklist)**
  - 6대 핵심 정책 한눈에 보는 체크리스트 및 FAQ 요약
